# Security Policy

## Supported versions

Only the latest public beta release of Data Modelling Tool is supported.

## Reporting a vulnerability

Do not report security vulnerabilities through public Issues or Discussions.

Use GitHub's [private vulnerability reporting](https://github.com/netplanet1981/data-modelling-tool-feedback/security/advisories/new).

Please include:

- A clear description of the problem
- Steps to reproduce it
- The affected browser and version
- The possible impact
- Any suggested mitigation

Do not include real credentials, confidential models, private DDL, or company data.

You should receive an initial response within seven days. Please allow time to investigate before disclosing the issue publicly.
