# Data Modelling Tool

Public feedback and discussions for **Data Modelling Tool**.

Data Modelling Tool is a browser-based visual editor for designing physical models for Snowflake. Version 0.1.0 is available as a free public beta.

## Web application

[Open Data Modelling Tool](https://xinxing.dev)

## Supported browsers

- Desktop Google Chrome
- Desktop Microsoft Edge

Mobile devices and other browsers are not supported or guaranteed in v0.1.

## Privacy and data

Model files are processed locally in your browser and are not uploaded to a service controlled by this project. The application does not collect analytics or telemetry.

Keep your own backups. Do not include confidential models, DDL, credentials, or company data in public issues or discussions.

Read the full [Privacy Notice](https://github.com/netplanet1981/data-modelling-tool-feedback/blob/main/PRIVACY.md).
