# Privacy Notice

Last updated: September 9, 2026

This notice explains how Data Modelling Tool handles information during the v0.1 public beta.

## Model data

Data Modelling Tool processes model files and generated DDL locally in your browser.

The application does not intentionally upload your models, imported DDL, generated DDL, or locally saved XML files to a service controlled by this project.

Opening or saving a file requires an action from you and uses browser file capabilities. You are responsible for keeping your own backups.

Do not submit confidential models, DDL, credentials, personal data, or company information through public GitHub Issues or Discussions.

## Accounts

Data Modelling Tool v0.1 does not provide user accounts or sign-in functionality.

## Local browser storage

The application may use browser storage for local interface preferences. This information remains in your browser unless your browser, operating system, extensions, or synchronization settings handle it differently.

You can remove locally stored preferences through your browser settings.

## Analytics and tracking

The application does not use product analytics, advertising trackers, or telemetry during the v0.1 public beta.

## Website hosting

The static website is hosted by Cloudflare. Cloudflare may process basic network and request information, such as IP addresses and security-related metadata, to deliver and protect the website.

Cloudflare handles this information under its own privacy policy:

https://www.cloudflare.com/privacypolicy/

## GitHub feedback

Issues, Discussions, comments, usernames, and other content submitted to the public feedback repository are processed by GitHub and are normally visible to the public.

GitHub handles this information under its own privacy statement:

https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

Do not post information that you do not want to make public.

## Security reports

Security vulnerabilities should be reported through GitHub's private vulnerability reporting:

https://github.com/netplanet1981/data-modelling-tool-feedback/security/advisories/new

Private security reports are visible to authorized repository maintainers and are processed through GitHub.

## Data retention

The project does not maintain a server-side database of user accounts or model files.

Public feedback remains on GitHub until it is edited or removed according to GitHub's features and policies. Hosting and security logs are controlled by Cloudflare according to its policies.

## Changes to this notice

This notice may be updated when the application adds or changes features that affect privacy. Material changes will be described in the public feedback repository.

## Contact

For general privacy questions, start a public Discussion without including personal or confidential information:

https://github.com/netplanet1981/data-modelling-tool-feedback/discussions

For a private security concern, use private vulnerability reporting instead.
